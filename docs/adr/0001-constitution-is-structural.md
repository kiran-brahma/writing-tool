# The constitution is enforced structurally

Frontier models are good at suggesting pleasing turns of phrase and at praising a draft, and both
quietly damage a Writer's voice: the first replaces it, the second talks the Writer out of the
rethinking that *was* the voice. Prompt instructions ban both, but they drift and they lose to
helpfulness, so the ban is enforced in structure instead — model output is constrained to a findings
schema with no field for rewritten prose, and no affordance anywhere inserts model-derived text. The
Writer's keyboard is the only path by which words enter a Document.

## Considered Options

- **Prompt instructions only.** Cheap, and unreliable in exactly the moments that matter.
- **Show rewrites behind an apply button.** Considerably more convenient, and the mechanism by which
  most writing tools dissolve the Writer's voice. Rejected: convenience here is the failure mode.

## Consequences

Some Writers will want the apply button and will not find it. Diagnosis text stays selectable so that
Findings can be kept and quoted; only the Quarantined rewrite is not.
